Example individuals use the prefix ex:.
In the expected results, rows are separated by ; and columns by a space.

SELECT ?specimen ?source WHERE {
  VALUES ?specimen { ex:CQ1_specimen_1 ex:CQ1_specimen_2 ex:CQ1_specimen_3 }
